## Reproducible discovery

1. Export `bf7e90bd42e66ad4b03d6c3e5e7e28ecf1890684` with `git archive --format=tar` into a new temporary directory.
2. Invoke the absolute Python executable with `-I -S`, an empty environment, and the exported root as the working directory; the discovery script prepends only that root and its `src` directory to `sys.path` and supplies import-time-only placeholders for the external cryptography backend.
3. In the exported root, map its sorted `tests/test_*.py` paths to `tests.<stem>` modules.
4. Load those modules with `unittest.defaultTestLoader.loadTestsFromNames`, reject `_FailedTest` imports, recursively collect each test's `id()`, and sort the complete result.

## Dirty-path release classification

Each machine-readable line is an exact repository-relative POSIX path, one TAB, and one closed release-class enum. The block is sorted by path. It contains no globs; entries not currently dirty are permitted so a reviewed future CI input can be classified before it changes.
